# NEON FRAME
Русскоязычная AI-фотостудия. Vinext / React / Cloudflare Workers.

## Генерация
Серверные /api/generate и /api/status. OPENAI_API_KEY хранится только в секретах Sites. Для подключения используйте плагин OpenAI Developers и его openai-platform-api-key skill, затем сохраните ключ через Sites environment variables (is_secret: true) и разверните версию повторно. Не вставляйте ключ в чат или клиентский код.
Модель: gpt-image-2.5-sunburst. API: /v1/images/generations без референса; /v1/images/edits с референсом. Документация: https://developers.openai.com/api/docs/guides/image-generation

1, 2 или 4 последовательных запроса. Каждый кадр получает исходный референс и отдельную композицию. Галочка добавляет требования сохранения внешности; это не пиксельная фиксация лица. Сходство не гарантировано. Картинки и референс находятся только в памяти вкладки; результат нужно скачать до закрытия.
API оплачивается владельцем. Сайт должен оставаться приватным. Сервер проверяет identity, Origin, размер, тип файла, параметры. Клиент блокирует повторное нажатие; сервер дополнительно отсеивает одинаковый requestId в одном Worker isolate на 10 минут (это не глобальная гарантия идемпотентности). Автоматических повторов нет.
